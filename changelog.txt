Breaking changes vs v4:
- xColors/yColors no longer accept false — unrecognized color options throw a TypeError
- polygon color values are lightweight { css() } objects, no longer chroma-js Color instances
- package is ESM-first ("type": "module") with an exports map: import gets ESM, require() gets CJS, script tags keep the UMD bundles in dist/
- node >= 18 is required
- patterns generated for a given seed differ from v4 (new RNG implementation)
